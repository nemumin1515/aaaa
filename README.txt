もちもちゅ おみくじ v7（ホーム画面アプリ版）
==========================================

■ 中身
  index.html             … アプリ本体（おみくじ960件・キャラクター画像も入っています）
  manifest.webmanifest   … ホーム画面アプリの名前・アイコン・向きの設定
  sw.js                  … ネットがなくても動くようにするしくみ
  icons/                 … アプリのアイコン

■ 置き方（GitHub Pages）
  このフォルダの中身を「まるごと」同じ場所に置いてください。
  例）https://（ユーザー名）.github.io/（リポジトリ名）/omikuji/ に
      index.html・manifest.webmanifest・sw.js・icons/ を置く
  ※ ファイル名（とくに index.html）と、フォルダの場所は変えないでください。
    変えると、ホーム画面のアプリが新しいほうを開けなくなります。

■ Androidタブレットのホーム画面に追加する
  1. Chromeで上のURL（…/omikuji/）を開く
  2. 右下の歯車（管理メニュー）→「ホーム画面に追加」
     （ボタンが出ないときは、Chrome右上の︙ →「ホーム画面に追加」または「アプリをインストール」）
  3. ホーム画面のアイコンから開く（全画面・横向きで開きます）
  4. 管理メニューの下に「● ネットがなくても動く準備ができています」と出ていればOK

■ 全画面について
  ・ホーム画面のアプリから開くと、最初から全画面・横向きで開きます。
  ・Chromeのページや「ショートカット」から開いたときは、最初に画面をタップしたところで全画面になります。
    （ブラウザの決まりで、タップする前は全画面にできません）
  ・アイコンの角に小さなChromeマークがついているときは「ショートカット」です。
    アプリとして入れ直すと、最初から全画面で開くようになります（︙ →「アプリをインストール」）。
  ・全画面をやめたいときは、管理メニューの「全画面をやめる」（アプリで開いたときはアプリを閉じる）。

■ 更新するとき（v7 など）
  1. index.html の中の「v7」（タイトルと管理メニューの表示）を新しい番号にする
  2. sw.js の CACHE = 'mochimochu-omikuji-v7' の番号も同じにする
  3. GitHub Pages に上書きで置く
  4. タブレットはネットにつないだ状態でアプリを開く（自動で新しい版になります。
     切り替わらないときは、アプリを一度閉じてもう一度開く）

■ 出たおみくじの記録
  Chromeで開いていたときの記録が、そのままアプリでも使われます（同じサイトなら共通）。
  Chromeの「閲覧データを削除」でサイトのデータを消すと、記録も消えます。
