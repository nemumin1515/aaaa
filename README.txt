もちもちゅ おみくじ v14（ホーム画面アプリ版）
==========================================

■ 中身
  index.html             … アプリ本体（おみくじ1120件（幼児を含む）・キャラクター画像も入っています）
  manifest.webmanifest   … ホーム画面アプリの名前・アイコン・向きの設定
  sw.js                  … ネットがなくても動くようにするしくみ
  icons/                 … アプリのアイコン

■ 置き方（GitHub Pages）
  このフォルダの中身を「まるごと」同じ場所に置いてください。
  例）https://（ユーザー名）.github.io/（リポジトリ名）/omikuji/ に
      index.html・manifest.webmanifest・sw.js・icons/ を置く
  ※ ファイル名（とくに index.html）と、フォルダの場所は変えないでください。
    変えると、ホーム画面のアプリが新しいほうを開けなくなります。

■ Androidタブレットのホーム画面に追加する
  1. Chromeで上のURL（…/omikuji/）を開く
  2. 右下の歯車（管理メニュー）→「ホーム画面に追加」
     （ボタンが出ないときは、Chrome右上の︙ →「ホーム画面に追加」または「アプリをインストール」）
  3. ホーム画面のアイコンから開く（全画面・横向きで開きます）
  4. 管理メニューの下に「● ネットがなくても動く準備ができています」と出ていればOK

■ 全画面について
  ・ホーム画面のアプリから開くと、最初から全画面・横向きで開きます。
  ・Chromeのページや「ショートカット」から開いたときは、自動では全画面になりません（v14から）。
    全画面にしたいときは、管理メニューの「全画面にする」を押してください
    （このときは Chrome の「全画面表示を終了するには…」という案内が出ます）。
  ・アイコンの角に小さなChromeマークがついているときは「ショートカット」です。
    アプリとして入れ直すと、最初から全画面で開くようになります（︙ →「アプリをインストール」）。

■ おみくじを引いたあと
  ミニプリンターで印刷すると「お店の人にわたしてね」の画面になり、そのまま止まります（自動ではもどりません）。
  お店の人は、印刷がすんだら画面下の「長押しで つぎの人へ」を1秒ほど長押ししてください。
  印刷できなかったときは「もう一度印刷」で同じおみくじを印刷しなおせます。
  印刷できたときだけ「出た」に数えます（v14から画像の保存はしません）。

■ ミニプリンター（Luck Jingle 系・例：PPS1_xxxx）で印刷する
  専用アプリは使わず、このアプリから Bluetooth で直接印刷します（Android の Chrome／ホーム画面のアプリ）。
  1. プリンターの電源を入れる。Luck Jingle アプリやパソコンとはつないでおかない
  2. 右下の歯車（管理メニュー）→「プリンターに接続」→ 一覧から PPS1_xxxx を選ぶ
     （一覧に出ないときは「一覧に出ないとき」で、すべての機器から選ぶ）
  3. 「テスト印刷（記録しない）」で試す
  4. 以後は、おみくじを引くと自動で印刷されます（画像の保存はしません）
  ・アプリを開き直したときは、もう一度「プリンターに接続」が必要なことがあります。
    （画面左下に「● プリンター接続中」と出ていれば接続できています）
  ・印刷の形は、管理メニューの「印刷の形」で選べます（前のタイプ＝もちもちゅ2人の看板／レシート形）。
  ・うまく印刷できないとき：管理メニューで「送り方」を「ゆっくり（安全）」に、
    すき間のあるラベル紙なら「用紙」を「ラベル（すき間あり）」にしてください。
  ・それでもだめなとき：管理メニューの「うまく印刷できないとき（しらべる）」を開き、
    ①〜④を1つずつ押して、どこで電源が切れるかを確かめ、「記録をコピー」した内容を送ってください。

■ 更新するとき（v14 など）
  1. index.html の中の「v14」（タイトルと管理メニューの表示）を新しい番号にする
  2. sw.js の CACHE = 'mochimochu-omikuji-v14' の番号も同じにする
  3. GitHub Pages に上書きで置く
  4. タブレットはネットにつないだ状態でアプリを開く（自動で新しい版になります。
     切り替わらないときは、アプリを一度閉じてもう一度開く）

■ 出たおみくじの記録
  管理メニューの「記録をすべてリセット」を2回続けて押すと、すべての区分が最初（20個ずつ）にもどります。
  おみくじの中身の並び（IDや区分）が変わったときは、記録は自動で最初からになります（文言だけの手直しではそのまま）。
  Chromeで開いていたときの記録が、そのままアプリでも使われます（同じサイトなら共通）。
  Chromeの「閲覧データを削除」でサイトのデータを消すと、記録も消えます。
